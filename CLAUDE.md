# CLAUDE.md — risk_experiment

Orientation for Claude Code sessions in this repo. Read this first.

## Project

de Hollander et al., *Nature Communications* (NCOMMS-24-63995B): "Rapid Changes
in Risk Attitudes Originate from Bayesian Inference on Parietal Magnitude
Representations." Combines 7T/3T fMRI (numerosity mapper + risky-choice task)
with Bayesian behavioural models to show that trial-to-trial uncertainty in
parietal magnitude representations drives changes in risk attitude. Currently in
the final-revision / figure-regeneration stage.

## Environment

- Conda env is **risk7t**. Run with `~/mambaforge/envs/risk7t/bin/python`.
- Package installed editable (`pip install -e .`); flat layout, `find_packages()`.

### bauer pin (important)

- The analysis-era Bayesian-model library is **bauer 0.1.0**, pinned as a git
  worktree at **`src/bauer`** (commit lineage `e246d78` of `ruffgroup/bauer`,
  the `refactor` branch). risk7t's editable install resolves `bauer` →
  `src/bauer/bauer`. `src/` is gitignored (`/src/`).
- Newer PyMC removed `pm.Data(..., mutable=True)`. Any code that **builds** a
  bauer model under a newer PyMC must first call
  `style.shim_pymc_for_bauer(pm)` (in `risk_experiment/figures/style.py`). It is
  a no-op on the analysis-era PyMC and changes no numbers — it only drops the
  removed `mutable` kwarg.

## Data

- Input data live at **`/data/ds-risk`** (BIDS + `derivatives/`). `get_sourcedata()`
  returns this path; scripts default `--bids_folder /data/ds-risk`.
- Behavioural model traces: `derivatives/cogmodels/[ses-{session}_]model-{label}[_{roi}]_trace.netcdf`.
- Decoded posterior PDFs: `derivatives/decoded_pdfs.volume*` (e.g.
  `decoded_pdfs.volume.denoise.natural_space`,
  `decoded_pdfs.volume.cv_voxel_selection.denoise.natural_space`).
- Sessions: `3t1`, `3t2`, `7t1`, `7t2`. `*1` = numerosity `mapper` task;
  `*2` = risky-choice `task`. TR is 2.3 s; mapper = 125 vols, task = 160 vols.

## Data access — `utils/data.py` only

All BIDS/derivatives access goes through `risk_experiment/utils/data.py`:

- `Subject(subject, bids_folder)` — the single source of truth. Methods cover
  behaviour, preprocessed/single-trial BOLD, masks, PRF parameters (volume +
  surface), confounds (fmriprep + RETROICOR), pupil/eyetracking, decoded PDFs
  (`get_decoded_pdf` / `get_decoding_info`), ROI timeseries.
- `get_all_subject_ids(drop_outliers=False)`, `get_all_subjects(...)`,
  `get_all_behavior(sessions=[...], ...)` — cohort helpers.
- **sub-24 is always excluded** (claustrophobia, only ever completed one
  session); `drop_outliers=True` additionally drops sub-03.
- `get_behavior` derives the key choice variables: `chose_risky`, `risky_first`,
  `n_risky`/`n_safe`, `log(risky/safe)`, uncertainty / median splits, etc.

## Cognitive models — `cogmodels/fit_model.py`

`build_model(model_label, df, roi)` maps a string label to a bauer model;
`get_data(model_label, session, bids_folder, roi)` assembles the dataframe
(joins decoding info for `neural*`, pupil for `pupil*`, ROI baselines for
`subcortical_*`). Run: `python -m risk_experiment.cogmodels.fit_model <label>
[session] --bids_folder /data/ds-risk [--roi ...]`. Output trace → see Data above.

Label scheme (numbers/letters are bauer `RiskRegressionModel` configs; session
is the main within-subject regressor):

- **`12` = PMCM — the paper's main model** (full priors, evidence + prior
  parameters varying by session).
- Four alternative models for comparison: **`klw`** (shared prior, equal noise),
  **`52`** (varying priors, equal noise), **`42`** (shared prior, varying noise),
  **`eu`** (expected-utility, `ExpectedUtilityRiskRegressionModel`).
- `neural*` / `rnp_neural*` — models with the **neural** decoded-uncertainty
  regressor (`sd` from `get_decoding_info`, mask `npcr`); these median-split or
  regress behaviour on neural uncertainty.
- `pupil*`, `subcortical_*`, `certainty_*` — exploratory regressor families.
- `rnp*` — `RNPRegressionModel` (relative-numerosity-preference parameterisation).

## Figures — `figures/` package

Final-revision figures are regenerated by `figures/figure_0N_*.py`. Each script
emits per-panel vector **ingredients** (PDF + SVG) into
`risk_experiment/revision/figures/`, plus a per-panel source-data TSV into
`risk_experiment/revision/figures/source_data/`. The final multi-panel figures
are then assembled in **Affinity Designer** (panel letters, schematics, brain
renders added there — never rescale panels; see
`revision/notes/AFFINITY_FIGURE_SIZES.md`).

- House style lives in `figures/style.py` (`set_style()`, `save_panel()`,
  `figures_dir()`, `source_data_dir()`, the palette, column widths
  `WIDTH_SINGLE/ONEHALF/DOUBLE`, and `shim_pymc_for_bauer`). Form only —
  changes no statistics.
- Verify exports: `python -m risk_experiment.figures.verify` (checks page size,
  ≥6 pt font floor, embedded editable Type-42 fonts, RGB).
- Present scripts: `figure_01_behavior.py`, `figure_03_alt_models.py`,
  `figure_04_model_comparison.py`, `figure_06_symbolic.py`. Figures 2 and 5 plus
  the schematic panels (1A, 1D, 6A) and brain renders (5A) are
  manual/Affinity-only and not (fully) script-generated.
- Brief: `revision/notes/FIGURE_REGENERATION_BRIEF.md`.

## Repo conventions

- **Data access only via `utils/data.py`** (`Subject` class) — never reach into
  BIDS paths directly elsewhere.
- Each **analysis stage is its own submodule** with co-located scripts:
  `prepare/`, `preproc/`, `cluster_preprocess/`, `glms/`, `encoding_model/`
  (PRF fit + decoding), `roi_analysis/`, `pupil/`, `physiology/`,
  `registration/`, `surface/`, `cogmodels/`, `visualize/`,
  `figures/`, `revision/`. Non-paper code (e.g. `tms_targeting/`,
  `session_lists/`, `cogmodels/plot_ppc.py`) is archived under `archive/`
  (paths preserved; see `archive/CLEANUP_NOTES.md`).
- Scripts take a positional `subject` (+ optional `session`) arg and
  `--bids_folder` (default `/data/ds-risk`).
- Figures are produced via the `figures/` package only; submission deliverables
  live in `revision/` (version-controlled), separate from input data.

## Gotchas

- Bash/Python execution may be denied in some sessions — prefer Read/Glob/Grep.
- When writing parameter NIfTIs through a binary `NiftiMasker`, force
  `float32` + `set_slope_inter(1, 0)` (see global CLAUDE.md NIfTI dtype trap).
