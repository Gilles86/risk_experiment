# Affinity Designer setup for the final figures (NCOMMS-24-63995B)

How to assemble the per-panel PDF *ingredients* (produced by
`risk_experiment/figures/figure_0N_*.py`, living in
`risk_experiment/revision/figures/`) into the six submission figures.

The Python scripts render each panel as a standalone vector PDF **already at
its final physical size**, with Helvetica embedded as editable text and the
smallest text at 8 pt. Your job in Affinity is to *arrange* panels and add
panel letters — **not to rescale them** (see the golden rule below).

---

## 1. Document setup (do this once per figure)

- **New Document → Print**, but set:
  - **Units: millimetres**
  - **Colour format: RGB/8** (Nature is online-first → RGB, *not* CMYK)
  - **DPI: 300** (only matters for the raster brain-renders in Fig 5A; all
    other art is vector and resolution-independent)
- **Canvas width** = the figure's target column width (table below).
- **Canvas height** ≤ **230 mm** so the figure + its (separately placed)
  legend still fits an A4 page.

## 2. Canvas width per figure (new numbering)

Nature Communications column widths: single **88 mm**, 1.5-column **120 mm**,
double/full **180 mm**. Pick the smallest width that keeps panels legible.

| Figure | Content | Canvas width |
|--------|---------|--------------|
| **Figure 1** | Task schematic + behaviour (A–D) | **180 mm** (double) |
| **Figure 2** | PMCM PPC + group/participant posteriors (A–C) | **180 mm** (double) |
| **Figure 3** | PPCs of the four alternative models (A–D) | **180 mm** (double) |
| **Figure 4** | ELPD model comparison (standalone) | **120 mm** (1.5-col) |
| **Figure 5** | nPRF maps + decoding + neural→behaviour (A–D) | **180 mm** (double) |
| **Figure 6** | Symbolic task + psychophysics (A–B) | **180 mm** (double) |

Height is whatever the panel grid needs — just keep it ≤ 230 mm.

## 3. The golden rule: place at 100 %, never scale the text down

Each panel's fonts were chosen so that **at the size the PDF was generated**,
the smallest text is 8 pt. If you drop a panel onto the canvas and shrink it,
the text shrinks with it and can fall below the editor's **6 pt floor**.

- **Place panels at 100 %** and arrange them. The panels were rendered at the
  fraction of the column they are meant to occupy, so they should already fit
  side-by-side within the canvas width.
- If a panel is genuinely too big/small for your layout, **don't rubber-band
  it** — tell me and I'll re-render that panel's script at the right width so
  the fonts stay correct. (Changing `figsize` in the script is the right fix;
  resizing in Affinity is not.)
- Safety margin if you *must* scale: min font after scaling = 8 pt × scale.
  Staying at scale ≥ **0.75** keeps you at ≥ 6 pt, but ≥ 7 pt (scale ≥ 0.875)
  is the comfortable target. Below that, re-render instead.

## 4. Panel letters and labels (added in Affinity, not in the PDFs)

The Python panels deliberately contain **no panel letters** — you add them.

- **Lowercase bold a, b, c …** (Nature house style), Helvetica, ~8–9 pt.
- Top-left, **outside** the panel axes, same offset on every panel.
- Any cross-panel text you add (a shared key, a bracket) — keep it Helvetica
  and ≥ 6 pt, ideally ≥ 7 pt.

## 5. Importing the schematic / brain panels (manual panels)

These are **not** generated by the scripts; place your existing artwork:

- **Fig 1A** trial-sequence schematic, **Fig 1D** PMCM cartoon,
  **Fig 6A** symbolic trial-sequence schematic — your Affinity/Illustrator
  source. Confirm all their text is ≥ 6 pt and these are author-created
  (the editor flagged 1A/1D/6A as "suspected third-party content").
- **Fig 5A** nPRF preferred-numerosity brain renders (3T & 7T) — raster, keep
  at ≥ 300 dpi at final size; keep the colourbar ticks/labels as vector text.

## 6. Export for submission

- **File → Export → PDF**.
- Preset: a press-ready PDF, but **embed fonts as text — do NOT "create
  outlines" / "convert text to curves"**. The editor needs selectable,
  editable Helvetica.
- **RGB**, no CMYK conversion. No image downsampling below 300 dpi.
- One PDF per figure: `Figure_1.pdf` … `Figure_6.pdf`.

## 7. Re-verify after export

Run the repo verifier on the exported figure to confirm it still passes
(page width, 6 pt floor, embedded text, vector, RGB):

```bash
~/mambaforge/envs/risk7t/bin/python -m risk_experiment.figures.verify Figure_1.pdf
```

If it flags a font < 6 pt, you scaled a panel down too far — re-place it at
100 % or ask for a re-render.
